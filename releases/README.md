## Installation Instructions

1. Download the `.mcaddon` file from the version folder above
2. Double-click to install in Minecraft Bedrock Edition
3. Activate both packs in your world settings
4. Enable Beta APIs if prompted

## Features

- Helper companions with Scout, Guard, and Forager modes
- Ore, animal, and monster finders
- Structure locator
- Home teleport and death recall
- Helper item requests with queued deliveries
- Repeatable quests
- Auto farm and launch jump actions
