# Adventure Helpers v0.1.13

A utility companion mod for Minecraft Bedrock Edition with helpers, ore finders, teleportation, and more!

## Download

- **Easy Install**: [AdventureHelpers.mcaddon](AdventureHelpers.mcaddon) - Double-click to install both packs
- **Separate Packs**: 
  - [AdventureHelpersBP.mcpack](AdventureHelpersBP.mcpack) - Behavior Pack
  - [AdventureHelpersRP.mcpack](AdventureHelpersRP.mcpack) - Resource Pack

## Installation

1. Download `AdventureHelpers.mcaddon`
2. Double-click the file to open it with Minecraft
3. Minecraft will automatically import both packs
4. Create a new world or edit an existing world
5. Go to **Behavior Packs** and activate "Adventure Helpers BP"
6. Go to **Resource Packs** and activate "Adventure Helpers RP"
7. Make sure to enable **Beta APIs** in world settings if prompted

## Features

### Helper Whistle
- Summon a per-player helper companion
- Modes: Scout, Guard, and Forager

### Finders
- **Ore Finder**: Locate nearby ores including lava with selectable scan ranges
- **Animal Finder**: Find nearby animals
- **Monster Finder**: Locate hostile mobs
- **Structure Locator**: Menu to find structures

### Teleportation
- **Home Teleport**: Quick return to your home base
- **Death Recall**: Teleport back to where you died

### Utilities
- **Helper Item Requests**: Request items with queued deliveries
- **Repeatable Quests**: Quest list with rollover progress
- **Auto Farm**: Automated farming actions
- **Launch Jump**: Quick vertical boost

## How to Use

1. Get the helper whistle: `/give @s ah:helper_whistle`
2. Right-click with the whistle to access the helper menu
3. Choose your helper mode and explore the various features!
